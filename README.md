# Адаптивный лендинг стоматологической клиники

Современный, минималистичный и доступный веб-сайт стоматологической клиники, разработанный с соблюдением требований дизайн-системы (`Design/DESIGN.md`), принципов доступности (a11y) и высокой производительности.

## 🚀 Команды запуска и сборки

Для работы с проектом требуется **Node.js 18+** и **npm 9+**.

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки (Vite Dev Server)
npm run dev

# 3. Проверка типов и сборка для продакшена
npm run build

# 4. Просмотр собранного проекта (Preview)
npm run preview
```

## ⚙️ Единая конфигурация проекта

Все текстовые материалы, контактные данные, список услуг, отзывы и флаги режимов вынесены в единый конфигурационный файл:

📂 **`src/config/clinicConfig.ts`**

В нем настраиваются:
* `name` — Название клиники
* `phoneDisplay` и `phoneRaw` — Контактные телефоны для отображения и ссылки `tel:`
* `email` — Электронная почта клиники
* `address` и `addressFallbackText` — Физический адрес и текстовый заголовок при его отсутствии
* `workingHours` — Часы работы клиники
* `mapEmbedUrl` и `mapRouteUrl` — Интерактивная карта (iframe) и ссылка для построения маршрута
* `services` — Список услуг, категорий, описаний и цен
* `processSteps` — Описание 3 шагов записи
* `reviews` — Карточки отзывов
* `isDemoMode` — Флаг демонстрационного режима (по умолчанию `true`)

## 🔌 Интеграция с backend (Обработчик заявок)

Подача заявок реализована через изолированный слой интеграции:

📂 **`src/services/bookingApi.ts`**

### Как подключить реальный сервер:
1. В `src/config/clinicConfig.ts` измените `isDemoMode: false`.
2. В `src/services/bookingApi.ts` указать ваш продакшен-эндпоинт в переменной `PRODUCTION_API_ENDPOINT` (например, `/api/v1/appointments` или URL вебхука CRM).
3. При отправке форма передает следующие данные в формате JSON:
   ```json
   {
     "name": "Иван Иванов",
     "phone": "+7 (999) 123-45-67",
     "serviceId": "caries-treatment",
     "preferredDate": "2026-10-15",
     "submittedAt": "2026-10-08T17:23:46.000Z"
   }
   ```
4. В демонстрационном режиме (`isDemoMode: true`) отправка на сервер не имитируется, а пользователю выводится явное уведомление: *«Демонстрационный режим: заявка не отправлена на сервер. Данные формы успешно прошли валидацию»*. Персональные данные не сохраняются в `localStorage`, логах или URL.

## 📋 Чек-лист демонстрационных данных перед публикацией

Следующие демонстрационные материалы необходимо заменить на реальные данные клиники:

1. **Контакты и реквизиты**:
   - Название клиники (`ДентаКлиник`)
   - Номер телефона (`+7 (495) 123-45-67`)
   - E-mail (`info@dentaclinic-demo.ru`)
   - Адрес (`г. Москва, ул. Лесная, д. 15`)
   - Ссылка на виджет Яндекс/Google карт
   - Номер медицинской лицензии и юридические реквизиты в подвале
2. **Изображения**:
   - Главная фотография клиники в Hero-секции (`src/config/clinicConfig.ts -> heroImage`)
   - Фотография кабинета в секции «О клинике» (`aboutImage`)
   *(Использованные в демо-версии фотографии взяты из лицензированной коллекции Unsplash).*
3. **Контент и отзывы**:
   - Согласовать текст блока «О клинике» с руководством
   - Заменить демонстрационные карточки отзывов (`isDemo: true`) на реальные отзывы пациентов
   - Проверить актуальность цен и наименований услуг
4. **Юридические документы**:
   - Заполнить реквизиты в тексте «Политики конфиденциальности» (`src/components/PrivacyModal.tsx`)

## 🎨 Дизайн и доступность

* **Сетка и адаптивность**: Проверено на экранах 360px, 390px, 768px, 1024px и 1440px.
* **Доступность (a11y)**: Управление с клавиатуры, видимые фокусы, `aria-invalid` для ошибок формы, поддержка `prefers-reduced-motion`.
* **Стиль**: Строго по `Design/DESIGN.md` (скругление 6px, нейтральная палитра 60-20-10-10, типографика Inter).
